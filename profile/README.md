## Repositories

Projects here vary in status and openness:

- Some are actively maintained open-source software, welcoming contributions.
- Some are research or learning projects shared publicly without contribution
  expectations.
- Some are private, proprietary, or personal and are not open for external
  contributions.

Always check a repository's own `README.md` and `LICENSE` before assuming
contribution rights or usage permissions.
